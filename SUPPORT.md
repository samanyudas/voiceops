# Support

## Report a problem

Use the [bug form](https://github.com/samanyudas/voiceops/issues/new?template=bug.yml).
Include the revision or release, runtime, operating system, reproduction steps, and observed output.
Remove tokens and private data from logs.

Use the [feature form](https://github.com/samanyudas/voiceops/issues/new?template=feature.yml) for a proposed capability.
Give the user need and acceptance criteria.

## Follow a fix

A merged PR does not mean a release contains the fix.
Tracked bug reports remain open until a qualifying stable release carries the recorded fix commit.
The workflow then asks the reporter to verify that release.
After 14 days without a human reply, it closes the unanswered follow-up under the documented policy.
Any human reply stops automatic closure.

Read the [issue lifecycle policy](docs/maintenance/issue-lifecycle.md) for exceptions and reopening behavior.
There are no support response-time guarantees.
