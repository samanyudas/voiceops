# Triage labels

The canonical triage roles use the same strings in GitHub.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | A maintainer must evaluate the issue. |
| needs-info | needs-info | The reporter must supply more information. |
| ready-for-agent | ready-for-agent | The issue is fully specified for an agent. |
| ready-for-human | ready-for-human | A human must implement the issue. |
| wontfix | wontfix | The issue will receive no implementation. |

Use these exact strings when a skill names a triage role.
Verify the labels in the selected repository before an issue operation requires them.
